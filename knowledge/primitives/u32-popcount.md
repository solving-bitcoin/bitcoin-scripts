# Checked u32 population count

`arithmetic::u32::popcount::u32_popcount` consumes one u32 represented by four
numeric byte limbs and returns the number of set bits. It range-checks each byte
before a 256-entry lookup, then adds the four byte population counts.

- **Input:** `byte[0] | byte[1] | byte[2] | byte[3]`, most significant byte
  first, with the least significant byte on top.
- **Output:** one numeric ScriptNum in `0..=32`.
- **Evidence:** `locally-reproduced` by boundary and representative-word tests,
  malformed-byte rejection tests, and a strict metric fixture.
- **Representative result:** 455 locking-script bytes, 13 serialized witness
  bytes across four `0xff` data items, 262 combined stack items, and no hints.
  The fragment contains 171 static non-push opcodes; this is not an executed
  opcode or deployment claim.
- **Execution class:** `unclassified`. The strict local executor uses a
  tapscript context and the combined stack limit; Bitcoin Core consensus and
  relay policy have not been differentially tested.

The 256-item table is generated by the locking script and removed before the
single result is returned. This is a fragment, so callers still provide any
terminal predicate, clean-stack rule, and byte-unique ScriptNum binding needed
by their protocol.
