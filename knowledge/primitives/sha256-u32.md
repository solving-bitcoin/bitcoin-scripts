# SHA-256 over u32 bytes

Implements SHA-256 using four byte-valued items per word and a shared Boolean
lookup table. It also exposes a two-block BIP340 tagged-hash fragment for
32-byte messages.

- **Position:** direct byte-oriented construction with representation reuse
  across several local hashes.
- **Evidence:** differentially validated against SHA-256 reference vectors,
  including Bitcoin's genesis header.
- **Representative result:** 512,428 script bytes for a 32-byte hashing
  fragment.
- **Tagged hash:** `sha256_tagged_hash_32bytes` computes
  `SHA256(tag_hash || tag_hash || message)` while consuming only the 32-byte
  message as witness data.
- **Tradeoff:** larger than the measured u4 construction for the same input,
  but interoperates directly with the u32 backend.
- **Deployment:** very large research fragment; strict feasibility must be
  established for each complete composition.

See the [implementation README](../../src/hashes/sha256/README.md),
[hash comparison](../comparisons/hashes.md), and catalog record
`hash/sha256-u32`.
