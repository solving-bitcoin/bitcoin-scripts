# F257 lookup arithmetic

Specializes u31 arithmetic for the field of 257 elements with compact
multiplication, centered constant chains, full/half direct tables, shared
log/exp tables, and exact-square tables.

- **Position:** exposes a local Pareto set rather than one universal
  multiplication algorithm.
- **Evidence:** locally reproduced exhaustively or with deterministic vectors.
- **Key tradeoff:** the 132-byte constant chain is best for isolated measured
  constants; shared tables lower per-query bytes but consume 129–385 items.
- **Composition constraint:** table memory may not coexist with a 512-item
  polynomial state under the consensus stack limit.
- **Trust boundary:** centered and canonical representations are not
  interchangeable without conversion.
