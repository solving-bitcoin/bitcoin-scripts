# u31 prime-field arithmetic

Provides modulus-agnostic arithmetic for canonical prime-field elements in one
positive ScriptNum and extension fields represented by coefficient vectors.
Concrete configurations now live under `src/fields`; multiplication uses
two-bit windows or specialized compact, constant, and lookup strategies.

- **Position:** avoids multi-limb overhead for moduli below `2^31`.
- **Evidence:** locally reproduced against native modular arithmetic.
- **Trust boundary:** inputs must be canonical; the backend does not range-check
  hostile coefficients.
- **Representative results:** M31 add 18 bytes, subtract 12, multiplication
  1,370; degree-four QM31 multiplication 12,901.
- **Alternatives:** lookup-based F257/F12289 paths when the field and reuse
  pattern justify table memory.

See the [generic backend README](../../src/arithmetic/u31/README.md), the
[M31/QM31 backend README](../../src/fields/m31/README.md), and catalog record
`arithmetic/u31`.
