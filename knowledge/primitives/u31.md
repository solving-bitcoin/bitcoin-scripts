# u31 prime-field arithmetic

Implements canonical prime-field elements in a single positive ScriptNum and
degree-four extensions as four coefficients. Multiplication uses quotient
hints or specialized compact/constant variants.

- **Position:** avoids multi-limb overhead for moduli below `2^31`.
- **Evidence:** locally reproduced against native modular arithmetic.
- **Trust boundary:** inputs must be canonical; witness quotients must be bound.
- **Representative results:** M31 add 18 bytes, subtract 12, multiplication
  1,400; degree-four QM31 multiplication 13,186.
- **Alternatives:** lookup-based F257/F12289 paths when the field and reuse
  pattern justify table memory.

See the [implementation README](../../src/arithmetic/u31/README.md) and catalog
record `arithmetic/u31`.
