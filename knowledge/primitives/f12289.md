# F12289 radix arithmetic

Specializes u31 arithmetic for the 12,289-element coefficient field used in
Falcon-oriented experiments. It includes compact multiplication and reusable
radix-table multiplication by constants.

- **Position:** radix decomposition trades setup and 225 table items for
  repeated constant products at deep stack positions.
- **Evidence:** locally reproduced with deterministic vectors and stack-limit
  checks.
- **Representative results:** compact multiplication 517 bytes; radix-128
  memory 781 bytes; depth-511 query 135 bytes.
- **Crossover:** current local documentation estimates the radix path becomes
  byte-competitive at roughly nine uses of one constant.
- **Limitation:** callers must separately account for unrelated live stack.
