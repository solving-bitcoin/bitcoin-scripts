# Reproducible research artifacts

Use one subdirectory per research question. Start from `TEMPLATE.md` and keep
small deterministic vectors beside the report. Large generated scripts should
be regenerated from recorded parameters and hashes rather than committed in
duplicate.

A completed experiment should update the knowledge catalog and relevant
comparison, negative-result, protocol, and open-problem pages. This directory
stores evidence; `knowledge/` stores the synthesized state of the art.
