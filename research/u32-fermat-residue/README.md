# Paired-byte Fermat residue experiment

The [report](metrics.json) is generated by the
[probe](../../examples/u32_fermat_residue_probe.rs), comparing the minimal
[public lane reducer](../../src/arithmetic/u32/residue.rs) with a
[comparison-only binary remainder circuit](baseline.rs).
The [knowledge page](../../knowledge/primitives/u32-mod65537.md) records the
question, hypothesis, proof, threat model, exact boundaries and limitations.
The source base is `bf9ee0bb34987a9130ad9dc13a06e18fef137296`; the delivered
commit and final test outcomes are recorded in the PR validation description.
Exact artifact hashes are actively checked, independently of documentation edits.
The immutable source/artifact revision is `87f324464d641e4263f696af3b0a4063c8c4ba94`. This manifest
and catalog annotation are a documentation-only follow-up; the PR records the
exact delivered revision against which the final required suite runs.

The representative runtime word is `0x89abcdef` in canonical most-significant
byte-first ScriptNums, with residue 17,476. Each complete computation leaf ends
in expected-residue `OP_EQUAL` and returns one truthy item. Four data items and
zero hints coexist at entry. Data-only witness size is full CompactSize
serialization but excludes leaf/control block/annex; it is not a complete
Taproot witness or transaction measurement.

The lane construction is **100 fragment bytes / 104 leaf bytes / 7 peak items**;
the baseline is **1,137 / 1,141 / 35** with the same 13-byte witness. The bitwise
approach is retained as a useful negative result, not a second public API.
All measured scripts receive `CompileOptions::ALL` through the centralized
compilation policy. Their exact fragment, leaf and witness SHA256 values,
embedded-lockfile compiler/interpreter identities, input word, terminal result
and local execution options are in the report. Dynamic executed-opcode counts
and complete-transaction validation weight are unavailable and recorded as null.

The report uses strict local tapscript with default minimal-number options,
synthetic empty transaction and a data-only budget. The shared hostile-witness
suite additionally uses the local consensus profile, disabling minimal-number
policy so raw canonicality rejection is proven by the script. Neither profile
establishes a complete consensus or policy transaction verdict. Classification
is `locally-reproduced` / `unclassified`.

The shared contract suite covers all hostile positions, numeric aliases under
their documented family contracts, short inputs, asymmetric values, runtime
preserved main/alt state and exact resource boundaries. Deliberate mutations
of actual policy-produced validation checks must make the same typed-error
assertion fail; valid controls and output cleanup use the same harness. The
numeric-only checked-zero sibling passes without changing production code.

Reproduce without refreshing unrelated metrics:

```sh
cargo run --locked --example u32_fermat_residue_probe > /tmp/u32-fermat-reproduced.json
cmp research/u32-fermat-residue/metrics.json /tmp/u32-fermat-reproduced.json
cargo test --locked --lib arithmetic::u32::residue
cargo test --locked --test u32_residue_contract
cargo test --locked --test primitive_metrics u32_mod65537_metrics_are_current
python3 tools/kb.py validate
CARGO_PROFILE_TEST_OPT_LEVEL=1 cargo test --locked -- --skip fields::
```

The broad test command uses CI's host opt-level 1, retaining default debug
assertions and overflow checks. Generated Script policy and measured bytecode
are unchanged; artifact hashes are checked under that profile as well.
